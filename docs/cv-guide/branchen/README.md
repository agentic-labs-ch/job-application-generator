# CV rules by Branche (research, 2026-09-27)

The owner wants the generator to produce CVs for other people too, not only for the owner
(2026-09-27). These files collect how CVs are written and read in each Branche, researched on
the web with sources, for the Swiss market. `../../cv-guide.md` stays the base rule set; a
Branche file adds what differs there.

The four Branchen follow the owner's model "CV-Generator: 4 Berufsfamilien × 4 Branchen"
(2026-09-27): the Branche sets how a CV looks and reads (layout, density, typeface, tone),
the Berufsfamilie sets the content.

| Branche | File | Sub-sectors |
|---|---|---|
| Finanz & Öffentlich | [finanz-oeffentlich.md](finanz-oeffentlich.md) | Banking, audit, IT audit, finance and controlling, trading, insurance, public administration |
| Beratung & Sales | [beratung-sales.md](beratung-sales.md) | Management consulting, IT consulting, presales, account management and B2B sales |
| Tech & Produkt | [tech-produkt.md](tech-produkt.md) | Software, cloud and operations, data and AI, security, product, research |
| Mensch & Kreativ | [mensch-kreativ.md](mensch-kreativ.md) | HR, recruiting, design and UX, communication and marketing |

Rules for these files:

- No real person's CV or personal data. Example bullets are fictional.
- Rules are summarised in our own words, with numbered sources at the end of each file.
- Job ads are listed with link and date as evidence for the keywords; they age, so check the
  date before relying on them.
- The owner's own facts stay in `data/cv.yaml`; these files never add facts about anyone.
