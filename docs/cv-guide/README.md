# Course material

`docs/cv-guide.md` draws its rules from the handouts of an application course ("ICT
Standortbestimmung") and cites them by file name. The handouts themselves are not included in
this repository: their copyright belongs to the course provider. The rules in
[`../cv-guide.md`](../cv-guide.md) are complete without them.

The rules by industry in [`branchen/`](branchen/) come from web research with numbered sources.
